# AI Response Evaluator

This project simulates evaluation of LLM-generated responses to user prompts. It ranks the quality of each response using scoring functions based on readability, keyword match, and length.

### 🔍 Features
- Input prompts and responses
- Scoring logic to evaluate responses
- Jupyter interface to explore results
- Easily extensible for human-in-the-loop annotation

### 🚀 Tech Stack
- Python, Jupyter, pandas
- textstat for readability
- Custom scoring logic

> Created for showcasing skills aligned with Turing's AI model evaluation role.
